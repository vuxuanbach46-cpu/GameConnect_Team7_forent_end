Bắt đầu từ đâu?

  1. Xem trang Items: ví dụ thêm / sửa / xoá / tìm kiếm gọi API thật.
  2. Đọc js/api.js để biết cách gọi API bằng axios.
  3. Tạo trang mới: copy pages/items.html + js/pages/items.js, thêm link vào js/layout.js.
